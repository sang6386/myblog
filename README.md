# 🌐 Blog cá nhân - myblog

## 🧱 Cấu trúc dự kiến
- `/` : Trang chủ (giới thiệu tổng quan)
- `/about` : Giới thiệu bản thân, kỹ năng, học vấn
- `/posts` : Các bài viết học tập và lập trình mạng
- `/contact` : Thông tin liên hệ (Email, GitHub, LinkedIn)

## 🛠️ Công cụ sử dụng
- Hugo v0.151.2
- Git & GitHub
- Sẽ triển khai GitHub Pages (Ngày 2)
- Theme: sẽ chọn ở Ngày 2
